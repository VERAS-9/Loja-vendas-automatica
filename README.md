# 🎯 Sniper Arena Store

Uma loja de vendas automáticas para itens de jogos, desenvolvida do zero com foco em segurança, usabilidade e automação.

🌐 **Acesse o site no ar:** [sniperarena-store.discloud.app](https://sniperarena-store.discloud.app)

## 🚀 Funcionalidades

- **Autenticação:** Login seguro com Google (OAuth 2.0) e login via e-mail/senha.
- **Checkout via Pix:** Geração de QR Code e chave Copia e Cola para pagamento.
- **Painel Administrativo:** Gestão de vendas, aprovação de pedidos e controle de estoque.
- **Chat em Tempo Real:** Sistema de atendimento integrado entre cliente e vendedor (estilo WhatsApp).
- **Notificações:** Integração com Webhooks do Discord para avisar sobre novos pedidos.
- **Segurança:** Proteção contra CSRF, cookies seguros (HTTPS), sanitização de SQL Injection e rotas de admin blindadas.

## 🛠️ Tecnologias Utilizadas

- **Backend:** Python, Flask, Flask-WTF (CSRF), Authlib (OAuth).
- **Banco de Dados:** SQLite.
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API).
- **Deploy:** Discloud (Hospedagem em nuvem).
